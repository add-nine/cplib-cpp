# cplib-cpp

競技プログラミング用のライブラリです。C++23以上、GCC 14以上を想定しています。

**ライブラリの作成には一部生成 AI を利用しています**。本リポジトリは、[AtCoder生成AI対策ルール](https://info.atcoder.jp/entry/llm-rules-ja) に基づき、ライブラリのソースコードを事前公開することを目的としています。

利用・改変などは自由ですが、本リポジトリは予告なく非公開・削除される可能性があるので、AtCoder での参照 URL が必要な場合は fork するなどしてご自身でリンクを用意することをおすすめします。
